# 2.1 Elementos básicos de la programación

Según la guía, al plantear una solución se divide generalmente en dos bloques: el **bloque de declaraciones** (donde se especifican las variables) y el **bloque de instrucciones** (que incluye entrada, procesamiento y salida de datos).

* **Ejemplo conceptual básico:**
  * **Bloque de declaraciones:** Definir las variables necesarias (por ejemplo: `base`, `altura`, `area`).
  * **Bloque de instrucciones:**
    1. **Entrada:** Solicitar la base y la altura.
    2. **Proceso:** Calcular el área multiplicando base por altura y dividiendo para dos.
    3. **Salida:** Mostrar el resultado en pantalla.
