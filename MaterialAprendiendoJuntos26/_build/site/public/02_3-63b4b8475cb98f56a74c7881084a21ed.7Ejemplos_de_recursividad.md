# 3.7 Ejemplos de recursividad

- **Descripción:** Ejemplo clásico para calcular el factorial de un número entero mediante un enfoque recursivo[cite: 402].

- **Ejemplo detallado en Python:**

    ```python
    def obtener_factorial(numero):
        # Caso base: detiene la recursión
        if numero <= 1:
            return 1
        # Caso recursivo: llamada a la misma función con estado reducido
        else:
            return numero * obtener_factorial(numero - 1)

    if __name__ == "__main__":
        res = obtener_factorial(5)
        print(f"El factorial de 5 es: {res}")  # Salida: 120
    ```
