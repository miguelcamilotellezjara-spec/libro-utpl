# 4.1 Introducción al manejo de excepciones

- **Concepto teóricamente fundamentado:** Según la guía, una excepción se define como un error lógico u operativo que ocurre mientras se ejecuta el programa y provoca su detención. Su manejo adecuado permite hacer un desvío en el flujo de ejecución para solucionar el problema en lugar de finalizar el programa abruptamente.

- **Ejemplo simple en Python:**

    ```python
    # Ejemplo básico de introducción a excepciones
    try:
        numero = int(input("Ingrese un número entero: "))
        print(f"Número ingresado correctamente: {numero}")
    except ValueError:
        print("Error: Debe ingresar obligatoriamente un número entero válido.")

    print("Fin del programa")
    ```
