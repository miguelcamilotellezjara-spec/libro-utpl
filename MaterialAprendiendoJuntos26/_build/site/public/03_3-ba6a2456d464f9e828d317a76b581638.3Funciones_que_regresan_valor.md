# 3.3 Funciones que regresan valor

- **Descripción:** A diferencia de los procedimientos, estas funciones realizan un cálculo o proceso y devuelven explícitamente un resultado utilizando la palabra clave `return`, el cual debe ser almacenado o utilizado en una variable.

- **Ejemplo detallado en Python:**

    ```python
    def calcular_area_terreno(largo, ancho):
        area = largo * ancho
        return area

    if __name__ == "__main__":
        resultado = calcular_area_terreno(50, 20)
        print(f"El área total del terreno es: {resultado} m²")
    ```
