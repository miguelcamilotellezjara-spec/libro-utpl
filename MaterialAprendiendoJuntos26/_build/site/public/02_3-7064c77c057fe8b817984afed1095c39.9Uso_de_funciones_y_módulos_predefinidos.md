# 3.9 Uso de funciones y módulos predefinidos

- **Descripción:** Python incluye funciones integradas automáticas (módulo `builtins` como `abs`, `max`, `sum`) y módulos estándar especializados que se pueden importar (como `math` o `random`)[cite: 405].

- **Ejemplo detallado en Python:**

    ```python
    import math
    import random

    if __name__ == "__main__":
        # Función predefinida (built-in)
        print("Valor máximo:", max(12, 45, 89))

        # Uso del módulo math
        print("Raíz cuadrada de 81:", math.sqrt(81))

        # Uso del módulo random
        print("Número aleatorio entre 1 y 10:", random.randint(1, 10))
    ```
