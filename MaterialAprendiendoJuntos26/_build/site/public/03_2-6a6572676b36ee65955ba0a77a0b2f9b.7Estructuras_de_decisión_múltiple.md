# 2.7. Estructuras de decisión múltiple

Se utiliza cuando es necesario evaluar más de dos opciones o rangos utilizando condiciones anidadas con `if`, `else` y `elif`.

* **Miniespecificación (Pseudocódigo):**

    Inicio
        Leer edad
        Si edad >= 0 y edad <= 12 Entonces
            Escribir "Infantil"
        Sino Si edad >= 13 y edad <= 17 Entonces
            Escribir "Adolescente"
        Sino Si edad >= 18 y edad <= 64 Entonces
            Escribir "Adulto"
        Sino
            Escribir "Adulto mayor"
        Fin Si
    Fin

* **Ejemplo en Python:**

    edad = int(input("Ingrese su edad: "))

    if edad >= 0 and edad <= 12:
        print("Infantil")
    elif edad >= 13 and edad <= 17:
        print("Adolescente")
    elif edad >= 18 and edad <= 64:
        print("Adulto")
    else:
        print("Adulto mayor")
