# 3.5 Variables locales y globales

- **Descripción:** 
  - **Variables globales:** Declaradas fuera de cualquier función y accesibles en todo el archivo o script.
  - **Variables locales:** Declaradas dentro de una función, con alcance exclusivo en su interior.

- **Ejemplo detallado en Python:**

    ```python
    # Variable global
    modo_operacion = "Producción"

    def evaluar_sistema():
        # Variable local
        intentos = 3
        print(f"Modo: {modo_operacion} | Intentos permitidos: {intentos}")

    if __name__ == "__main__":
        evaluar_sistema()
    ```
