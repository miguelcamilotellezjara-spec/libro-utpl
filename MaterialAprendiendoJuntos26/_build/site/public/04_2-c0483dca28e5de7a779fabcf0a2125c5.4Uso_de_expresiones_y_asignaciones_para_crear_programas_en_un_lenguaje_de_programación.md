# 2.4. Uso de expresiones y asignaciones para crear programas en un lenguaje de programación

Este tema combina la lectura de datos, el uso de expresiones matemáticas y el formateo de cadenas para crear programas funcionales.

* **Ejemplo en Python (Calcular el área de un triángulo):**

    # Entrada de datos con conversión (casting) a float
    base = float(input("Ingrese la base del triángulo: "))
    altura = float(input("Ingrese la altura del triángulo: "))

    # Proceso (Asignación y expresión)
    area = (base * altura) / 2

    # Salida usando f-strings
    print(f"El área del triángulo es: {area:.2f}")
