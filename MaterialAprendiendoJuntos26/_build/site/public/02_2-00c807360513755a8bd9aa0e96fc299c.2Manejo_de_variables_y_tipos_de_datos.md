# 2.2 Manejo de variables y tipos de datos

Una variable es un espacio en memoria para almacenar un dato. En las miniespecificaciones se usa una nomenclatura con tipo y dominio, mientras que en Python se usa tipado dinámico.

* **Miniespecificación:**

    (edad, i[1-n]) <--- 20

  (Donde `edad` es la variable, `i` indica entero y `[1-n]` su dominio).

* **Ejemplo en Python:**

    # Python asigna el tipo de dato automáticamente (tipado dinámico)
    edad = 20
    nombre = "Carlos"  # Tipo str
    precio = 10.5      # Tipo float
    es_activo = True   # Tipo bool
