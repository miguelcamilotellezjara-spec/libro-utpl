# 1.5 Diagramas de Flujo

## Ejemplo simple de Diagramas de Flujo

Los diagramas de flujo representan gráficamente la solución usando símbolos estandarizados:

* **Paralelogramos:** Se usan para operaciones de datos (Entrada `GET` o Salida `PUT`).
* **Rectángulos / Procesos:** Para asignaciones y cálculos.
* **Rombos:** Para la toma de decisiones (condicionales).
* **Óvalos:** Para los límites (Inicio / Fin).
* **Líneas de flujo con flechas:** Para unir los símbolos y establecer el orden de ejecución.
