# 4.4. Métodos y técnicas de lectura de archivos

- **Concepto teóricamente fundamentado:** Una vez que un archivo ha sido abierto en modo lectura (`'r'`), Python provee diversas funciones y métodos integrados para extraer la información almacenada en el almacenamiento secundario según las necesidades específicas del programa:
  - `read()`: Lee todo el contenido del archivo y lo devuelve como una única cadena de texto (string). Es útil para archivos pequeños, pero puede consumir demasiada memoria RAM si el archivo es muy pesado.
  - `readline()`: Lee el archivo línea por línea, avanzando el puntero de lectura en cada llamada. Es ideal cuando se necesita analizar o filtrar el contenido de forma secuencial.
  - `readlines()`: Lee todas las líneas del archivo y las almacena organizadas dentro de una lista, donde cada elemento de la lista representa una línea del documento.
  - **Iteración directa con bucle `for`**: Representa la forma más óptima y eficiente en Python para procesar archivos grandes, ya que recorre el archivo línea por línea de manera dinámica sin saturar la memoria del sistema.

- **Ejemplos prácticos en Python:**

    ```python
    # Creación previa de un archivo de prueba para el ejemplo
    with open("empleados.txt", "w", encoding="utf-8") as archivo:
        archivo.write("Ana Gómez - Ingeniería\n")
        archivo.write("Carlos Ruiz - Redes\n")
        archivo.write("Elena Torres - Analítica de Datos\n")

    # 1. Uso de read() para leer todo el contenido de una vez
    print("--- 1. Usando el método read() ---")
    try:
        with open("empleados.txt", "r", encoding="utf-8") as archivo:
            contenido_total = archivo.read()
            print(contenido_total)
    except FileNotFoundError:
        print("El archivo no existe.")

    # 2. Uso de readlines() para obtener una lista de líneas
    print("--- 2. Usando el método readlines() ---")
    try:
        with open("empleados.txt", "r", encoding="utf-8") as archivo:
            lineas_lista = archivo.readlines()
            print(f"Lista de líneas: {lineas_lista}")
            print(f"Segunda línea del archivo: {lineas_lista[1].strip()}")
    except FileNotFoundError:
        print("El archivo no existe.")

    # 3. Uso de iteración directa (Recomendado para eficiencia)
    print("\n--- 3. Recorriendo el archivo línea por línea con un bucle for ---")
    try:
        with open("empleados.txt", "r", encoding="utf-8") as archivo:
            for numero, linea in enumerate(archivo, start=1):
                print(f"Línea {numero}: {linea.strip()}")
    except FileNotFoundError:
        print("El archivo no existe.")
    ```
