# 3.2 Funciones que no regresan valor (Procedimientos)

- **Descripción:** Son funciones que ejecutan una serie de tareas u operaciones (como mostrar mensajes en pantalla), pero no devuelven ningún resultado mediante la instrucción `return` (retornan `None` por defecto).

- **Ejemplo detallado en Python:**

    ```python
    def mostrar_estado_red():
        print("Estado del enlace: Conectado y operativo.")

    if __name__ == "__main__":
        mostrar_estado_red()
    ```
