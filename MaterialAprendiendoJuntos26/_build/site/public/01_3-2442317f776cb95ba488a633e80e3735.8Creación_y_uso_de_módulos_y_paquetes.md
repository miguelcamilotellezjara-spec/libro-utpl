# 3.8 Creación y uso de módulos y paquetes

- **Descripción:** 
  - **Módulo:** Cualquier archivo con extensión `.py` que contiene funciones y variables reutilizables.
  - **Paquete:** Una carpeta que agrupa varios módulos y contiene un archivo obligatorio llamado `__init__.py`.

- **Estructura del proyecto:**

    ```text
    mi_proyecto/
    ├── __init__.py
    ├── operaciones.py
    └── principal.py
    ```

- **Contenido de `operaciones.py`:**

    ```python
    def sumar(a, b):
        return a + b
    ```

- **Uso en `principal.py`:**

    ```python
    from operaciones import import sumar

    if __name__ == "__main__":
        print(f"Suma modular: {sumar(10, 15)}")
    ```
