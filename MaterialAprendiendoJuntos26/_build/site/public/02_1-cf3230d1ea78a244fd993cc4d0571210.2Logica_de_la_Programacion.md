# 1.2 Lógica de la Programación

## Ejemplo simple de Metodología de solución de problemas

Según la guía, el ciclo metodológico para resolver un problema de computación consta de las siguientes fases secuenciales:

1. **Entender el problema**
2. **Planear la lógica**
3. **Escribir el código**
4. **Traducir el código**
5. **Probar el código**
6. **Poner el programa en producción**
7. **Mantener el programa**
