# 4.2. Uso de excepciones en soluciones

- **Concepto teóricamente fundamentado:** En Python se emplean las palabras reservadas `try` y `except` para capturar y administrar posibles errores en tiempo de ejecución. Asimismo, se pueden utilizar excepciones específicas y lanzar errores de forma manual mediante `raise Exception`[cite: 401].

- **Ejemplo basado en la guía (Basado en el ejemplo de división y validación de rangos):**

    ```python
    bandera = True
    while bandera:
        try:
            numerador = float(input("Ingrese un valor numérico como numerador: "))
            denominador = float(input("Ingrese un valor numérico como denominador: "))
            
            # Validación con excepción personalizada
            if numerador < 20:
                raise Exception("Error: El numerador debe ser mayor o igual a 20.")
                
            division = numerador / denominador
            print(f"La división es: {division:.2f}")
            bandera = False
            
        except ValueError:
            print("Error: Se debe ingresar un valor numérico válido.")
        except ZeroDivisionError:
            print("Error: No se puede dividir por cero.")
        except Exception as e:
            print(e)

    print("Fin del programa")
    ```
