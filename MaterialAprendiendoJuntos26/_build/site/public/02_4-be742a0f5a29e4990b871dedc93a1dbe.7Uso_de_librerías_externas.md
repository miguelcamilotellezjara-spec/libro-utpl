# 4.7. Uso de librerías externas

- **Ejemplo en Python:** Una vez instalada una librería externa (por ejemplo, `requests` para consumir datos web o herramientas de análisis), se importa en el script para utilizar sus funciones:

    ```python
    # Ejemplo utilizando una librería externa (requests)
    # Asegúrese de instalarla previamente con: pip install requests
    import requests

    try:
        respuesta = requests.get("[https://api.github.com](https://api.github.com)")
        if respuesta.status_code == 200:
            print("Conexión exitosa con la API de GitHub.")
            print(f"Tipo de contenido: {respuesta.headers.get('Content-Type')}")
        else:
            print("No se pudo establecer la conexión.")
    except Exception as e:
        print(f"Error en la petición de red: {e}")
    ```
