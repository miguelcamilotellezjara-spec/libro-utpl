# 4.6. Proceso de instalación de librerías externas

- **Explicación:** Tal como se destaca en las generalidades de gestión de paquetes de Python en la guía, las librerías externas que no forman parte de la biblioteca estándar se instalan mediante el gestor de paquetes oficial `pip`.

- **Comando en la terminal o consola:**

    ```bash
    pip install pandas
    ```

- *(Este comando descarga e instala la librería externa solicitada junto con sus dependencias en el entorno de Python).*
