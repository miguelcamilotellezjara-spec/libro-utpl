# 2.11. Arreglos bidimensionales (Matrices / Listas anidadas)

* **Descripción:** Organizan datos en filas y columnas (simulando matrices). Se accede a sus elementos mediante un par de índices `[fila][columna]`. En Python se implementan mediante listas anidadas[cite: 15].

* **Miniespecificación (Pseudocódigo):**

    Inicio
        dimensionar notas[3][4]
        dimensionar promedios[3]
        Para estudiante desde 0 hasta 2 Hacer
            Para nota desde 0 hasta 3 Hacer
                Leer nota_ingresada

            Fin Para
        Fin Para
        Para estudiante desde 0 hasta 2 Hacer

            Para nota desde 0 hasta 3 Hacer

            Fin Para

        Fin Para
        Para estudiante desde 0 hasta 2 Hacer
            Escribir "El promedio del estudiante", estudiante + 1, "es:", promedios[estudiante]
        Fin Para
    Fin

* **Ejemplo detallado en Python (Registrar las notas de 3 estudiantes en 4 asignaturas/evaluaciones, calcular el promedio individual y almacenarlo en un arreglo unidimensional):**

    # Declaración de la matriz para almacenar notas (3 filas, 4 columnas) inicializada en 0
    notas = [[0] * 4, 
             [0] * 4, 
             [0] * 4]

    # Declaración del arreglo unidimensional para almacenar los promedios
    promedios = [0] * 3

    # Ingreso de notas por teclado mediante bucles anidados
    for estudiante in range(3):  # Recorre filas (estudiantes)
        for nota in range(4):  # Recorre columnas (notas)
            nota_ingresada = input(f"Ingrese la nota {nota + 1} del estudiante {estudiante + 1}: ")
            notas[estudiante][nota] = float(nota_ingresada)

    # Cálculo del promedio por estudiante
    for estudiante in range(3):
        suma = 0
        for nota in range(4):
            suma = suma + notas[estudiante][nota]
        promedios[estudiante] = suma / 4  # Guarda el promedio en el arreglo

    # Mostrar los promedios almacenados
    print("\nPromedios de los estudiantes:")
    contador = 1
    for promedio in promedios:
        print(f"El promedio del estudiante {contador} es: {promedio:.2f}")
        contador = contador + 1
