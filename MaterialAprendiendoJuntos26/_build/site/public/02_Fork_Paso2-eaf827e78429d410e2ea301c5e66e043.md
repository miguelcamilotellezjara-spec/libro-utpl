# Parte 2: Clonación del repositorio en el equipo local

- **Descripción:** Guía detallada para clonar el repositorio bifurcado desde GitHub hacia el entorno local de trabajo mediante comandos de terminal y su integración en el entorno de desarrollo.

- **Pasos a seguir para la clonación:**
  - **Paso 4:** En su computadora, abra la consola de comandos Git Bash.
  - **Paso 5:** Regrese a Google Chrome, acceda al repositorio que clonó en su cuenta, copie el enlace HTTPS desde el botón verde de descarga (**Code**) y péguelo en la ventana de Git Bash.
  - **Paso 6:** Escriba el comando `git clone` seguido de la URL que copió y presione Enter para descargar los archivos en su equipo local.
  - **Paso 7:** Abra su entorno de desarrollo habitual (como Visual Studio Code o PyCharm) y cargue la carpeta del repositorio que acaba de descargar para explorar su estructura y archivos.
