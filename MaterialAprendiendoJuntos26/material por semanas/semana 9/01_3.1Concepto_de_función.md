# 3.1 Concepto de función

- **Descripción:** Una función es un conjunto de instrucciones estructurado bajo un único nombre para cumplir un objetivo específico, permitiendo la reutilización de código y aplicando la estrategia "Divide y Vencerás".

- **Ejemplo detallado en Python (Ejemplo conceptual básico de función):**

    ```python
    # Ejemplo conceptual básico de función
    def saludar():
        print("Bienvenido al módulo de procesamiento de datos.")

    if __name__ == "__main__":
        saludar()
    ```
