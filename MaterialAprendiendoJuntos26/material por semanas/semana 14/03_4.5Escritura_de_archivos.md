# 4.5. Escritura de archivos

- **Concepto teóricamente fundamentado:** Para almacenar datos de manera persistente, se abre el archivo en modo escritura (`'w'` para sobrescribir o `'a'` para añadir).

- **Ejemplo en Python:**

    ```python
    # Ejemplo de escritura en un archivo de texto
    try:
        # Abre el archivo en modo escritura ('w')
        with open("reporte.txt", "w", encoding="utf-8") as archivo:
            archivo.write("Reporte de Estudiantes - UTPL\n")
            archivo.write("Estudiante 1: Juan Pérez\n")
            archivo.write("Estudiante 2: María Gómez\n")
        print("Datos escritos correctamente en el archivo.")
    except Exception as e:
        print(f"Ocurrió un error al escribir el archivo: {e}")
    ```
