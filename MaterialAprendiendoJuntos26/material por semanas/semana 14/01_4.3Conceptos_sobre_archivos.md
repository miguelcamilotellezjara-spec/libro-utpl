# 4.3. Conceptos sobre archivos y modos de apertura

- **Concepto teóricamente fundamentado:** Hasta el estudio de las estructuras en memoria, los datos utilizados solo existen en la memoria volátil (RAM) mientras el programa se ejecuta, lo que significa que al finalizar o apagarse el equipo, la información se pierde. El uso de archivos permite lograr la **persistencia de datos** en el almacenamiento secundario (como discos duros o SSD)[cite: 402].
- Para manipular archivos en Python, se utiliza la función nativa `open(nombre_archivo, modo)`, donde el **modo** define la operación que se va a realizar[cite: 402]:
  - `'r'`: Lectura (Read) - El archivo debe existir previamente[cite: 402].
  - `'w'`: Escritura (Write) - Crea el archivo o sobrescribe su contenido si ya existe[cite: 402].
  - `'a'`: Anexar (Append) - Añade datos al final del archivo sin borrar el contenido existente[cite: 402].
- Es una buena práctica de programación utilizar la estructura `with`, ya que gestiona automáticamente el cierre del archivo al finalizar el bloque de código, liberando recursos del sistema[cite: 402].

- **Ejemplo práctico en Python:**

    ```python
    # Ejemplo de conceptos y modos de apertura de archivos
    nombre_archivo = "registro_estudiantes.txt"

    # 1. Escritura inicial o creación del archivo ('w')
    try:
        with open(nombre_archivo, "w", encoding="utf-8") as archivo:
            archivo.write("--- Registro Académico UTPL ---\n")
            archivo.write("Estudiante: Miguel Téllez\n")
        print("Archivo creado y escrito exitosamente en modo 'w'.")
    except Exception as e:
        print(f"Error al escribir: {e}")

    # 2. Añadir nueva información sin borrar la anterior ('a')
    try:
        with open(nombre_archivo, "a", encoding="utf-8") as archivo:
            archivo.write("Materia: Fundamentos de Programación\n")
        print("Información agregada exitosamente en modo 'a'.")
    except Exception as e:
        print(f"Error al añadir: {e}")

    # 3. Lectura del archivo completo ('r')
    try:
        with open(nombre_archivo, "r", encoding="utf-8") as archivo:
            contenido = archivo.read()
            print("\nContenido actual almacenado en el archivo:")
            print(contenido)
    except FileNotFoundError:
        print("El archivo especificado no fue encontrado.")
    ```
