# 2.5. Estructuras de decisión simple – if

Permite ejecutar un bloque de código únicamente si la condición lógica evaluada es verdadera (`True`).

* **Miniespecificación (Pseudocódigo):**

    Inicio
        Leer edad
        Si edad >= 18 Entonces
            Escribir "Usted es mayor de edad."
        Fin Si
    Fin

* **Ejemplo en Python:**

    edad = int(input("Ingrese su edad: "))

    # Estructura de decisión simple
    if edad >= 18:
        print("Usted es mayor de edad.")
