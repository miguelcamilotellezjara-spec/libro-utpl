# 2.6. Estructuras de decisión doble – if/else

Permite bifurcar el flujo del programa: un bloque se ejecuta si la condición es verdadera y otro bloque (`else`) si la condición es falsa.

* **Miniespecificación (Pseudocódigo):**

    Inicio
        Leer calificacion
        Si calificacion >= 7.0 Entonces
            Escribir "Aprobado"
        Sino
            Escribir "Reprobado"
        Fin Si
    Fin

* **Ejemplo en Python:**

    calificacion = float(input("Ingrese su nota final: "))

    if calificacion >= 7.0:
        print("Aprobado")
    else:
        print("Reprobado")
