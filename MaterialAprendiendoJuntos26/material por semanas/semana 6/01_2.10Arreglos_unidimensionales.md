# 2.10. Arreglos unidimensionales (Listas)

* **Descripción:** Permiten almacenar múltiples valores ordenados en una sola variable mediante el uso de índices que comienzan en la posición `0`.

* **Miniespecificación (Pseudocódigo):**

    Inicio
        Leer tamanio
        dimensionar numeros[tamanio]
        valoresIngresados <- "Valores ingresados:\n"
        Para indice desde 0 hasta tamanio - 1 Hacer
            Leer numero
            Si numero >= 20 y numero <= 40 Entonces
                numeros[indice] <- numero
            Sino
                numeros[indice] <- 100
            Fin Si
        Fin Para
        Para cada i en numeros Hacer
            valoresIngresados <- valoresIngresados + i + "\n"
        Fin Para
        Escribir valoresIngresados
    Fin

* **Nota conceptual (Listas vs Tuplas):**
  * **Listas (`[]`):** Son **mutables**, lo que significa que sus elementos pueden ser modificados, añadidos o eliminados después de haber sido creadas.
  * **Tuplas (`()`):** Son **inmutables**, es decir, una vez creadas no se pueden alterar, añadir ni eliminar elementos, lo que las hace más seguras para datos constantes.

* **Ejemplo detallado en Python:**

    # Solicitar el tamaño del arreglo
    tamanio = int(input("Ingrese el tamaño del arreglo: "))

    # Declaración del arreglo con el tamaño ingresado inicializado en 0
    numeros = [0] * tamanio

    # Acumulador de cadena para almacenar los valores
    valoresIngresados = "Valores ingresados:\n"

    # Ingresar valores en el arreglo con validación
    for indice in range(tamanio):
        numero = int(input(f"Ingrese un número para la posición {indice + 1}: "))

        # Verificación del rango permitido (20-40)
        if 20 <= numero <= 40:
            numeros[indice] = numero
        else:
            numeros[indice] = 100  # Valor por defecto si está fuera de rango

    # Agregar los valores a la cadena acumuladora recorriendo la lista
    for i in numeros:
        valoresIngresados = f"{valoresIngresados}{i}\n"

    # Mostrar los resultados
    print(valoresIngresados)
