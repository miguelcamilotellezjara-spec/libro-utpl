# Resumen de la Semana 1 a la Semana 7 (Primer Bimestre)

## Semana 1: Introducción a la programación y solución de problemas
* Se estudian las fases del ciclo de desarrollo de software (entender el problema, planear la lógica, escribir, probar, traducir y mantener).
* Se define el concepto de lógica de programación y la estructura de los algoritmos (entradas, procesos y salidas).
* Se introducen las miniespecificaciones (pseudocódigo detallado) y los diagramas de flujo como herramientas visuales de diseño.

## Semana 2: Lenguajes de programación y entornos
* Se diferencian los lenguajes de alto nivel (como Python) frente a los de bajo nivel (lenguaje de máquina y ensamblador).
* Se distinguen los lenguajes compilados de los interpretados.
* Se abordan los paradigmas de programación (imperativo, orientado a objetos y funcional).
* Se configura el entorno con Python, el uso de IDEs (PyCharm, VS Code) y la gestión de código mediante el control de versiones con Git y GitHub.

## Semana 3: Fundamentos de programación, variables y operadores
* Se estructuran los programas en bloques de declaraciones y de instrucciones.
* Se estudian las variables y los tipos de datos básicos (`int`, `float`, `str`, `bool`).
* Se analizan los operadores aritméticos, relacionales y lógicos, aplicando rigurosamente las reglas de precedencia.

## Semana 4: Estructuras de decisión
* Se aprende a controlar el flujo de ejecución mediante tomas de decisiones:
  * Estructura simple (`if`).
  * Estructura doble (`if/else`).
  * Estructura de decisión múltiple (anidación de condiciones).

## Semana 5: Ciclos repetitivos (Bucles)
* Se estudian las estructuras iterativas para automatizar tareas repetitivas: el ciclo `while` (comparación al inicio) y el ciclo `for` (iteración controlada).
* Se implementan variables auxiliares fundamentales como contadores y acumuladores.

## Semana 6: Arreglos unidimensionales
* Se introduce el concepto de estructuras estáticas y vectores, enfocándose en el uso de listas (`list`) en Python.
* Se aprende el manejo de índices (comenzando en 0), métodos de manipulación (`append`, `del`) y el recorrido mediante bucles por índices o de forma directa.

## Semana 7: Arreglos bidimensionales (Matrices)
* Se profundiza en el almacenamiento estructurado de datos organizados en filas y columnas.
* Se implementan listas anidadas en Python y se utilizan bucles `for` anidados para el recorrido, ingreso y procesamiento de los elementos de una matriz.
