# 1.10 Entornos de Programación

## Ejemplo de Entornos de Programación

* **Intérprete interactivo (REPL / Consola):** Entorno donde se pueden ejecutar comandos de Python de forma inmediata escribiendo `python3` en la terminal.
* **Entornos de Desarrollo Integrado (IDE) y Editores:** Herramientas para escribir y probar proyectos completos, como **PyCharm** (IDE especializado de JetBrains) o **Visual Studio Code** (editor ligero de Microsoft) mediante archivos con extensión `.py`.
