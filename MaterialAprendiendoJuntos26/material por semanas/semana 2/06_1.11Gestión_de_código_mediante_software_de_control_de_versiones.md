# 1.11 Gestión de Código mediante Control de Versiones

## Ejemplo de Gestión de Código mediante Control de Versiones

El control de versiones permite almacenar y hacer seguimiento de las modificaciones en los archivos de un proyecto. Usando **Git** en la terminal junto con plataformas en la nube como **GitHub**, los comandos básicos de gestión son:

* **`git clone <url>`:** Descarga una copia completa de un repositorio remoto a la máquina local.
* **`git add .`:** Agrega los archivos modificados al área de preparación.
* **`git commit -m "mensaje"`:** Guarda formalmente los cambios en el historial local con una breve descripción.
* **`git push`:** Envía los cambios guardados al servidor en la nube (GitHub).
* **`git status`:** Verifica qué archivos han sido modificados.
* **`git pull`:** Actualiza el proyecto local con los cambios más recientes del servidor.
