# 1.9 Paradigmas de Programación

## Ejemplo de Paradigmas de Programación

* **Programación Imperativa:** Paradigma base basado en una secuencia de instrucciones que modifican el estado usando variables, asignaciones, condicionales y ciclos (es el enfoque principal de esta guía).
* **Programación Orientada a Objetos (POO):** Organiza el código mediante clases, objetos, encapsulación y herencia (ej. en Python, C++, Java).
* **Programación Funcional:** Trabaja sobre datos mediante funciones puras evitando estados compartidos o variables globales (ej. funciones como `map`, `filter`).
